Purrlor desktop 2.0 is a rebuild on Electron, and it now runs on **Linux** as well as Windows.

| You're on | Download |
|---|---|
| Windows 10 or 11 | **Purrlor-Setup.exe**: run it, no admin rights needed |
| Ubuntu, Debian, Mint, Pop!_OS | **purrlor_amd64.deb**: open it with App Center, or `sudo apt install ./purrlor_amd64.deb` |
| Other Linux | **Purrlor-x86_64.AppImage**: make it executable and run it (needs FUSE 2: `libfuse2`) |

What's new:
- Linux: Ubuntu and other distributions, with the tray, notifications, the unread count on the dock, start on login, screen sharing (through the system's own picker under Wayland), and voice keybinds that work while another window is in front (X11 sessions).
- A new look to match the web app: a welcome screen for picking your server, loading and "couldn't connect" screens that retry by themselves, a server switcher in the title bar, and Purrlor's own screen-share picker.
- Right-click menus with spelling suggestions, copy and save image, and open link in browser.
- Zoom with Ctrl + / Ctrl − / Ctrl 0 (and Ctrl + scroll), reload with F5, full screen with F11.

**Coming from 1.x on Windows:** it updates by itself as usual and keeps your server and settings. Sign-ins can't come over from the old engine, so you'll sign in again once. If you use encrypted chats, have your recovery key or passphrase ready.
