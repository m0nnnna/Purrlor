The Purrlor desktop app for Windows and Linux.

| You're on | Download |
|---|---|
| Windows 10 or 11 | **Purrlor-Setup.exe**: run it, no admin rights needed |
| Ubuntu, Debian, Mint, Pop!_OS | **purrlor_amd64.deb**: open it with App Center, or `sudo apt install ./purrlor_amd64.deb` |
| Other Linux | **Purrlor-x86_64.AppImage**: make it executable and run it (needs FUSE 2: `libfuse2`) |

On first launch it asks which Purrlor server to connect to (purr.meowops.net by default). It keeps itself up to date; the `.sig` files are what it checks each download against.
