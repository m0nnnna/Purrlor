Purrlor 1.1 adds WATCH, live streaming and a lot of polish to chat.

### What's new

- **WATCH:** a Videos tab on profiles and a video page, with everyone's videos, stories and live streams from this server and its peers on one page, view counts, and "Also add to WATCH" for a public post's videos.
- **Live streams:** go live in 720p30 from the browser, or from OBS over WHIP. A setup page and a streamer dashboard with a preview, stream health, sharing links and chat moderation (delete, timeout, ban). A full player on the watch page, a Streams tab on profiles, live streams on Home, and replays kept for 72 hours.
- **Badges:** 4-letter coloured pills that admins make and give out, shown here and on peers (`purrlor badges`).
- **Chat:**
  - Messages send without waiting on each other; a failed one shows Not sent with Retry, and a send stuck on a dead connection no longer locks the composer.
  - Reply in one step: Reply on desktop, swipe right on a phone.
  - Click a message for its actions on a computer, or long-press it on a phone.
  - Spoiler images and videos, per attachment or with `/spoiler`.
  - NSFW channels get a tag in the list and a warning the first time you open one.
  - Deleted encrypted messages no longer show as "[unable to decrypt]".
- **Music:** shuffle, repeat, a now-playing view, and a link for each album.
- **Security:** a homeserver can only vouch (OpenID) for its own users.

### For admins

- Streaming adds three containers: **Redis** (which voice now needs too), **Egress** for replays, and **Ingress** for OBS. `purrlor update` starts them all.
- **OBS needs UDP 7885** reaching the server, like 7882. New installs open it in ufw. On an existing server, open it yourself (`sudo ufw allow 7885/udp`) and forward it on any router or firewall in front. Without it, browser streams still work.
- New commands: `purrlor streams` (list, end, delete, export) and `purrlor badges`. Streaming settings (`STREAMING`, `STREAM_UPLINK_MBPS`, `STREAM_MAX_LIVE`, …) are in [docs/streaming.md](https://github.com/m0nnnna/Purrlor/blob/master/docs/streaming.md).
- A server behind `OUTBOUND_PROXY` needs `ingress` in `OUTBOUND_NO_PROXY`.
- On edge, `purrlor update` now catches up with images that landed after its checkout.

### Updating

```bash
sudo purrlor backup
sudo purrlor update
```
