The first stable release of the Purrlor server: a Discord-shaped home for chat, voice and a social feed, on Matrix, that you can run yourself.

**Servers now choose a channel.** `stable` (the default) moves only to releases like this one; `edge` follows every commit on `master`, the way every server did until now. See [docs/releases.md](https://github.com/m0nnnna/Purrlor/blob/master/docs/releases.md).

### What's in 1.0

- **Chat:** Spaces as servers and rooms as channels, threads, replies that notify who you replied to, reactions and custom emotes, up to 8 attachments a message, end-to-end encryption, and an IRC mode.
- **Voice and video:** voice channels on LiveKit, screen sharing and Watch Together, each with its own volume.
- **Social:** posts, comments and the Feed, 24-hour stories from people you follow, and profile pages with galleries of up to 100 pieces an album, all shared with other Purrlor servers through federation.
- **Home, Feed and Chat on the rail**, with Back that goes back, on the web, in the Windows app and in the Android app.
- **Message sounds** in nine styles, with their own volume.
- **Running it:** a one-line installer, prebuilt images for amd64 and arm64, `purrlor` for backups, alerts, metrics, accounts, moderation and `!bug` reports.

### Updating

```bash
sudo purrlor backup
sudo purrlor update
```

A server from before releases moves onto the stable channel with that update and says so. To keep following every commit: `sudo purrlor update --edge`.
