Purrlor 1.2 lets you choose which badges you show, and adds push for the new Android app.

### What's new

- **Badges:** if you have more than one, a picker in your settings chooses which show and in what order.
- **UnifiedPush:** the push gateway can now notify the new native Android app (no Google services) as well as browsers. Notifications open the right room.

### For admins

- Nothing to change. The push gateway keeps its UnifiedPush endpoints in `UNIFIEDPUSH_FILE` (`/data/unifiedpush.json` in the compose file), which `purrlor update` sets up.
- Android 2.0.1 is a separate release (`android-v2.0.1`): a native app with push, tap-to-open and calls that keep running in the background, with Mute and Leave on the call notification.

### Updating

```bash
sudo purrlor backup
sudo purrlor update
```
